# xRenovation Admin
## Quick Demo

![Admin_Demo](./gifs/xrenovation_admin_demo_gif.gif)

### xRenovation_Admin is used to administrate the xRenovation app

#### What can i do within the app?

- Publish/Delete/Edit existing houses

- Publish/Delete existing comments

- Delete corrections

- Find the users to ban

#### Technologies:

- Kotlin, Flow, Coroutines + MVVM

- Jetpack Navigation

- Dagger

- Retrofit2

- Glide

- FireBase Auth, FireBase Storage, FireBase Database

- Yandex MapKit
